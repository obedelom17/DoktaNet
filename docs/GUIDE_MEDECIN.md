# Guide médecin
1. Inscription avec le numéro d'ordre. Le compte est actif après validation par l'administrateur.
2. Disponibilités : cocher les jours et saisir début/fin (créneaux de 30 min, heure de Lomé).
3. Congés : bloquer une période. Les rendez-vous déjà pris sont à annuler manuellement.
4. Agenda : Lancer (ouvre la visio), Dossier (allergies, antécédents, ordonnances passées, accès tracé), Notes, Terminer.
5. Ordonnance : saisir médicaments, posologie, durée. Signer et envoyer. Elle est signée électroniquement et vérifiable par code.
6. Messages : répondre au patient depuis la carte du rendez-vous.
7. Assistant IA : agenda, résumé de dossier, reformulation de notes, brouillon d'ordonnance. Le médecin valide et signe toujours.
8. Mon compte : activer la 2FA (obligatoire si REQUIRE_2FA=1).
