# Guide administrateur
1. Validation : vérifier numéro d'ordre ou licence, puis Valider ou Refuser.
2. Comptes : rechercher un utilisateur. Réinitialiser le mot de passe génère un mot de passe temporaire à communiquer (option : réinitialiser aussi la 2FA). L'action est tracée dans les journaux d'audit.
3. Litiges : traiter les signalements, ajouter une note de résolution.
4. Statistiques : consultations, chiffre d'affaires brut, commission, comptes actifs.
5. Journaux d'audit : table `audit_logs` (accès dossiers, ordonnances, actions admin).
